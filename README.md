# BloxClient

BloxClient is an independent Windows app for finding, saving and launching Roblox games. Games
open in the official Roblox Player. BloxClient never asks for your Roblox password or cookie,
doesn't modify Roblox's files and doesn't inject code into the game.

BloxClient isn't affiliated with or endorsed by Roblox Corporation.

- Website and download: https://budioustheiii.github.io/BloxClient/
- Website source: the [`website`](https://github.com/BudioustheIII/BloxClient/tree/website) branch

BloxClient is built with Tauri 2, Rust, React and TypeScript.
