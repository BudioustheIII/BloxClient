# Changelog

## 0.1.0 (unreleased)

The first public version of BloxClient, an independent desktop client and launcher for Roblox.
BloxClient is not affiliated with or endorsed by Roblox Corporation.

### Added

- Browse, search and open Roblox experiences, then launch them through the official Player.
- Continue Playing, including games started outside BloxClient.
- Library with pinned games, collections and locally stored favorites.
- Friends page for people you add by username, with their public presence.
- Deployment manager that installs verified Roblox versions from official servers.
- FFlag editor with profiles, presets, import, export and automatic backups.
- Performance center for CPU, GPU, RAM, Roblox memory and network.
- Dark, light and system themes, accent colors, and an animated background.

### Fixed

- The animated background no longer stays on a still image after some launches.
- The animated background uses less GPU and adapts faster on integrated graphics.
- Upgrading with the installer's default option keeps the Windows startup preference.

### Known limitations

- The installer isn't code-signed yet, so Windows may show a security warning.
- There are no in-app updates yet. Install new versions manually.
- Roblox sign-in isn't available, so account favorites, real friends lists and account switching
  are unavailable.
- In-game FPS isn't shown, because measuring it would mean touching the game process.
